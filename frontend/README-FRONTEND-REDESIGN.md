# MediPredict Frontend Refresh

This refresh is an additive redesign inspired by premium editorial healthcare/technology sites: large typography, cinematic imagery, scroll reveals, telemetry visuals, subtle parallax and responsive layouts.

## Visual assets
The existing project medical images are reused locally so the deployment does not depend on hotlinked stock URLs. For future additions, healthcare imagery can be sourced from Unsplash and healthcare animations from LottieFiles. LottieFiles currently provides free healthcare animations under its applicable licenses; review the license for each asset before redistribution.

## Motion
- Scroll reveal via IntersectionObserver
- Animated health telemetry waveform
- Ambient medical/AI glow
- Hover lift on cards
- Desktop pointer parallax
- Reduced-motion accessibility support
